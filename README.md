# کوریدور فارسی | Quoridor FA 🎯

![Build APK](https://github.com/vahidzangooei96-stack/quoridor-fa/actions/workflows/build.yml/badge.svg)

بازی حرفه‌ای **کوریدور (Quoridor)** برای اندروید — کاملاً فارسی، راست‌به‌چپ، با هوش مصنوعی Minimax و آمادهٔ انتشار در کافه‌بازار.

> 📦 پکیج: `ir.quoridorfa.game` | 🤖 minSdk: 21 (اندروید ۵ به بالا) | 📄 سند طراحی: [docs/Quoridor-FA_TechDesign_TestPlan.pdf](docs/Quoridor-FA_TechDesign_TestPlan.pdf)

## 📥 دانلود و نصب

آخرین نسخهٔ امضاشده را از بخش [**Releases**](../../releases) دانلود کنید، یا مستقیم از **Actions** (تب Actions → آخرین اجرای Build APK → Artifacts).

نصب: فایل APK را روی گوشی باز کنید و اجازهٔ «نصب از منابع ناشناس» را بدهید.

## 🎮 امکانات نسخهٔ ۱.۰.۰

- ✅ قوانین رسمی Gigamic: حرکت، پرش مستقیم، حرکت مورب (ساید‌استپ)، ۱۰ دیوار برای هر بازیکن، قانون «هیچ دیواری راه را نمی‌بندد»
- ✅ بازی دونفرهٔ محلی + بازی با ربات در ۳ سطح (آسان / متوسط / سخت)
- ✅ هوش مصنوعی **Minimax با هرس آلفا-بتا** (سخت: عمق ۳، بودجهٔ زمانی ۱.۵ ثانیه)
- ✅ رابط کاملاً فارسی با فونت وزیرمتن و اعداد فارسی
- ✅ قرار دادن دیوار با کشیدن انگشت (پیش‌نمایش سبز/قرمز legality)
- ✅ بازگشت (Undo)، صدا، لرزش، هایلایت حرکات مجاز و نشانگر نوبت
- ✅ حجم فوق‌سبک: ~۶۲ کیلوبایت (هدف سند: زیر ۴۰MB ✓)

## 🧪 کیفیت (دروازهٔ کیفی سند طراحی)

- ۳۸ تست واحد روی هستهٔ خالص جاوا: همهٔ قوانین + پرش‌ها + هندسهٔ دیوار + تشخیص برد
- **۵۰۰ بازی تصادفی** با صفر استثنا و اثبات نگه‌داشتِ «مسیر همیشه باز» بعد از هر دیوار
- تست AI: برد فوری، جلوگیری از برد حریف، پایان‌یافتگی بازی AI-vs-AI، رعایت بودجهٔ زمانی

## 📂 ساختار مخزن

| مسیر | توضیح |
|---|---|
| `app/src/core/` | هستهٔ بازی و AI — **جاوا خالص بدون اندروید** (قابل تست روی JVM) |
| `app/src/main/` | لایهٔ اندروید: MainActivity، BoardView (بوم سفارشی)، منابع، فونت وزیرمتن |
| `tests/` | مجموعه تست ۳۸ موردی هسته |
| `scripts/build_apk.sh` | خط تولید APK: aapt2 → javac → d8 → zipalign → apksigner |
| `docs/` | سند طراحی فنی + برنامه تست (۱۳ صفحه) |
| `.github/workflows/` | ساخت خودکار APK و انتشار در Releases با هر تگ `v*` |

## 🔨 ساخت دستی

```bash
# پیش‌نیاز: JDK 21 و Android SDK (build-tools;35.0.0 + platforms;android-34)
export ANDROID_HOME=/path/to/android-sdk
bash scripts/build_apk.sh
# خروجی: Quoridor-FA-v1.0.0.apk
```

## 🚀 انتشار نسخهٔ جدید

```bash
git tag v1.0.1 && git push origin v1.0.1
# GitHub Actions به‌صورت خودکار APK می‌سازد و به همان تگ در Releases می‌چسباند
```

## 🔑 امضا

فایل `quoridor.keystore` (رمز: `quoridorfa2026`) به‌صورت محلی نگهداری می‌شود و داخل مخزن نیست.
برای انتشار در کافه‌بازار از همین کلید برای همهٔ نسخه‌های بعدی استفاده کنید و نسخهٔ پشتیبان امن از آن داشته باشید.
