## 🧪 کیفیت (دروازهٔ کیفی سند طراحی)

- ۴۸ تست واحد روی هستهٔ خالص جاوا: همهٔ قوانین + پرش‌ها + هندسهٔ دیوار + تشخیص برد
- **۵۰۰ بازی تصادفی** با صفر استثنا و اثبات نگه‌داشتِ «مسیر همیشه باز» بعد از هر دیوار
- تست AI: برد فوری، جلوگیری از برد حریف، پایان‌یافتگی بازی AI-vs-AI، رعایت بودجهٔ زمانی

## 📂 ساختار مخزن

| مسیر | توضیح |
|---|---|
| `app/src/core/` | هستهٔ بازی و AI — **جاوا خالص بدون اندروید** (قابل تست روی JVM) |
| `app/src/main/` | لایهٔ اندروید: MainActivity، BoardView (بوم سفارشی)، منابع، فونت وزیرمتن |
| `tests/` | مجموعه تست ۴۸ موردی هسته |
| `scripts/build_apk.sh` | خط تولید APK: aapt2 → javac → d8 → zipalign → apksigner |
| `docs/` | سند طراحی فنی + برنامه تست (۱۳ صفحه) |
| `.github/workflows/` | ساخت خودکار APK در هر تگ/dispatch (آرتیفکت) — انتشار Release با کلید اصلی به‌صورت دستی انجام می‌شود |

## 🔨 ساخت دستی

```bash
# پیش‌نیاز: JDK 21 و Android SDK (build-tools;35.0.0 + platforms;android-34)
export ANDROID_HOME=/path/to/android-sdk
bash scripts/build_apk.sh
# خروجی: Quoridor-FA-v1.0.3.apk
```

## 🔑 امضا

فایل `quoridor.keystore` به‌صورت محلی نگهداری می‌شود و نباید وارد مخزن عمومی شود.
برای انتشار در کافه‌بازار همیشه از همان کلید امضا استفاده کنید و نسخهٔ پشتیبان رمزگذاری‌شده داشته باشید. رمزها را در مخزن یا README ننویسید؛ در صورت نیاز از متغیرهای محیطی `QUORIDOR_STORE_PASSWORD`، `QUORIDOR_KEY_PASSWORD` و `QUORIDOR_KEY_ALIAS` استفاده کنید. اگر APK قبلی با کلید دیگری امضا شده باشد، نصب به‌روزرسانی روی آن ممکن است شکست بخورد.
