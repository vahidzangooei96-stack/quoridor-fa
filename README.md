# کوریدور فارسی | Quoridor FA 🎯

بازی حرفه‌ای **کوریدور (Quoridor)** برای اندروید — کاملاً فارسی، راست‌به‌چپ، با هوش مصنوعی و آمادهٔ انتشار در کافه‌بازار.

> 📦 پکیج: `ir.quoridorfa.game` | 🎮 پلتفرم: Android | 📄 سند طراحی: [docs/Quoridor-FA_TechDesign_TestPlan.pdf](docs/Quoridor-FA_TechDesign_TestPlan.pdf)

---

## 📋 دربارهٔ بازی

کوریدور یکی از محبوب‌ترین بازی‌های استراتژیک رومیزی جهان (ساختهٔ شرکت Gigamic) است:
دو بازیکن روی صفحهٔ ۹×۹ تلاش می‌کنند مهرهٔ خود را زودتر به سمت مقابل برسانند؛
هر بازیکن می‌تواند در نوبت خود **یک خانه حرکت کند** یا **یک دیوار (از مجموع ۱۰ دیوار) قرار دهد** —
اما هیچ دیواری نمی‌تواند مسیر حریف را کاملاً ببندد. ترکیب مسیریابی هوشمندانه و مانع‌سازی، این بازی را به یک نبرد ذهنی تمام‌عیار تبدیل می‌کند.

## 🗺️ نقشه راه پروژه

| فاز | محتوا | وضعیت |
|---|---|---|
| **F0** | تأیید طراحی + راه‌اندازی مخزن + CI ساخت APK | 🔄 در جریان |
| **F1** | هستهٔ بازی (قوانین رسمی Gigamic) + تست‌های واحد | ⏳ |

| **F5** | تست کامل + بستهٔ انتشار کافه‌بازار | ⏳ |
| **F6** | انتشار عمومی | ⏳ |
